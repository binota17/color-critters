# COLOR CRITTERS — Project Overview

## Vision
COLOR CRITTERS is a bright, charming, pixel-art 2D puzzle platformer for the web. Players control colorful creatures with distinct abilities and solve room-based puzzles by switching between them and interacting with the environment.

## MVP
- Single-player, browser-based, room/level-based side-view gameplay.
- Phaser 3 + TypeScript + Vite.
- Arcade Physics.
- Two playable Critters: MOSS and ZIPPY.
- Target: 10 introductory levels eventually; first prototype is a single puzzle room.
- Bright, colorful pixel-art aesthetic.
- No backend, multiplayer, combat, or procedural level generation in MVP.

## Core Pillars
1. Simple: easy-to-learn controls.
2. Clever: puzzles require planning and coordination.
3. Charming: colorful world, cute characters, appealing animation and feedback.

## Prototype Goal
Validate the core loop: move/jump, switch Critters, use abilities, interact with puzzle objects, open an exit and complete a room.
