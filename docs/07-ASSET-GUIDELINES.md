# COLOR CRITTERS — Asset Guidelines

## Art direction
- Bright pixel art.
- Friendly, cute creature designs.
- Pastel/bright palette with readable contrast.
- Grass, sky, flowers, colorful mechanisms and welcoming environments.
- Avoid dark, grim, horror or post-apocalyptic visuals.

## Pixel-art consistency
- Use consistent pixel scale and sprite dimensions where practical.
- Avoid filtered scaling/blur.
- Use pixel-friendly font and UI icons.
- Keep sprite silhouettes readable.

## Placeholder policy
Use simple placeholder shapes or temporary sprites during early milestones. Do not block gameplay implementation on final art.

## Critters
- MOSS: green, growth/plant visual language.
- ZIPPY: yellow, electricity/spark visual language.

## Asset implementation
Organize assets by category: Critters, environment, objects, UI, tiles, audio and fonts. Keep asset keys and file paths documented.
