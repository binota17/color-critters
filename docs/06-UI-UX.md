# COLOR CRITTERS — UI/UX Guidelines

## Visual direction
- Bright, cheerful and colorful.
- Cute pixel-art style.
- Clean layouts and legible text.
- Avoid dark horror or grim aesthetics.
- Pixel art should not be blurred.

## Screens (planned)
- Main Menu: Play, Continue, Settings, Credits.
- World Map: worlds, level nodes and progress.
- Gameplay HUD: active Critter, inactive Critter, ability/interact prompt, pause and reset.
- Pause Menu.
- Level Result: stars, time, moves, collectibles, retry, next level, map.

## Gameplay HUD
Keep HUD minimal. Show only information relevant to the current room and active Critter.

## Interaction prompt
Show a prompt such as “E — Activate Node” only when a valid target is in range.

## MVP priority
UI can initially use placeholders. Focus on movement and puzzle validation before building polished UI.
